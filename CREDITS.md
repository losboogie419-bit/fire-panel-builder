# CREDITS

Fake It To You Make It is an original educational fire-alarm wiring game created by Los Boogie (losboogie419-bit), released under the GNU General Public License v3.

## Ideas and Inspiration

The following open-source projects (all GPL v3) provided valuable ideas for game design, progression, and circuit interaction concepts. No code was copied from them, as they are implemented in C++ with Raylib, while this project is pure HTML5 + vanilla JavaScript for offline mobile-first use. Concepts were adapted and reimplemented from scratch.

- **VoltQuest** (https://github.com/VoltQuest/VoltQuest)
  - Drag-and-drop wiring with live circuit simulation
  - JSON-based level definitions
  - Educational hands-on electronics gameplay

- **Circuit Artist** (https://github.com/lets-all-be-stupid-forever/circuit-artist)
  - Logic gates as interactive, playable components
  - Real-time simulation feedback and truth tables
  - Pixel/visual circuit construction ideas

- **OpenTowers** (https://github.com/seanpm2001/OpenTowers)
  - Floor-by-floor tower progression inspired by Tiny Tower style
  - Unlocking higher floors through completed lower ones

## Other Notes

- Fire alarm device terminal data for "Pro Mode" skins drawn from publicly available Notifier and Hochiki manuals (educational use).
- All generic device values are original for the game and clearly labeled.
- Pixel art tech character and UI elements created for this project.

Thank you to the authors of the above projects for sharing their work under GPL.
